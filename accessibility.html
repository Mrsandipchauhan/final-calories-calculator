Accessibility Statement

Last Updated: August 06, 2026

NutriRoute is committed to ensuring digital accessibility for people with disabilities. We are continually improving the user experience for everyone, and applying the relevant accessibility standards to guarantee that our interactive food calculators remain fully inclusive.

1. Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. It defines three levels of conformance: Level A, Level AA, and Level AAA. NutriRoute is conformant with WCAG 2.1 Level AA.

2. Accessibility Features on NutriRoute

We implement various features to facilitate easy use of our platform:

  • Keyboard Navigation: All menu dropdowns, customize chips, search bars, and calculator fields can be accessed and manipulated using standard keyboard controls.
  • Contrast Ratios: Text elements are optimized to meet WCAG AA contrast ratio targets to aid legibility for users with color vision deficiencies.
  • Screen Reader Optimization: Interactive elements have semantic tags and proper ARIA labels (e.g. aria-label, aria-live) to translate dynamic order updates correctly.
  • Responsive Design: All pages adapt to any screen size, from desktop monitors to mobile phones, ensuring a consistent and usable experience across devices.
  • Focus Indicators: Visible focus states are provided on all interactive controls so users navigating via keyboard can always track their position on the page.

3. Compatibility with Browsers and Assistive Technology

NutriRoute is designed to be compatible with the following assistive technologies:

  • Screen readers (NVDA, JAWS, VoiceOver)
  • Speech recognition software
  • Screen magnification tools
  • Alternative input devices
